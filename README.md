# 第七史诗 幸运冲刺 最优策略求解器

一个用于计算《第七史诗》"幸运冲刺"小游戏最优策略的工具。

## 在线使用

直接用浏览器打开 `index.html` 即可，无需后端。

```bash
# 本地启动（可选）
python -m http.server 8000
# 然后访问 http://localhost:8000/index.html
```

## 功能

- **冲距离**：最小化到达目标的期望能量消耗。
- **循环刷装备**：最大化单位能量获得的装备奖励数量（跑到失败或 450m 硬上限）。
- **一图流**：生成适合手机截图分享的主线操作流程。
- **蒙特卡洛验证**：用模拟验证 DP 算法的计算结果。

## 数据来源

成功率数据主要来自社区实测表格：

- [Google Sheets - Epic Seven Lucky Dash Data](https://docs.google.com/spreadsheets/d/1eVb9WLeG2r82JMuuVKfdIPnPNTqK1ElzZv0RBXucvQQ/edit?gid=1963991156#gid=1963991156)

`success_rates.js` 中数据标注了来源（注释中）：

- **实测**：来自上述社区实测表格。
- **推算**：根据已知点线性插值或外推得到，可能存在误差。

当前实测数据覆盖到 480m，但 280m、330m、340m、420m、430m、470m 等位置暂时为空，已用推算值填充。

## 欢迎补充数据

如果你有更多的实测数据，欢迎通过以下方式贡献：

1. 直接修改 `success_rates.js`，更新对应距离的成功率数值。
2. 提交 Pull Request 或开 Issue。

补充数据时请注意：

- 尽量提供多次尝试的样本量。
- 如果某个距离是里程碑（100m 倍数），请特别注明，因为里程碑成功率通常有特殊加成。

## 算法说明

- 使用**值迭代（Value Iteration）**求解动态规划问题。
- 状态表示为 `(位置, 防护次数, 助跑次数, 超级幸运次数)`。
- "循环刷装备"模式使用 **Dinkelbach 算法** 求解分数规划问题 `max R/E`。
- 节点跨越概率通过独立的值迭代计算，用于预测装备获取件数。
